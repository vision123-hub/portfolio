# Vision Parajuli — Portfolio

A personal developer portfolio for **Vision Parajuli**, a Computer Science student at Gachon University interested in programming, web development, and building practical projects.

## About

The portfolio introduces Vision, shares skills developed through coursework, and highlights selected Web Programming course projects. Its dark, blush-pink, and rose-gold design features Vision's sunset photograph and a small animated Mochi cat that floats with the page.

## Technologies

- HTML5 for the page structure and content
- CSS3 for styling, responsive layouts, animations, and reduced-motion support
- CSS animations for Mochi's tail, ears, eyes, and idle movement

The portfolio does not require a framework, external libraries, or a build step.

## Portfolio sections

- **Home** — Introduction, university and major, subtitle, and sunset photograph
- **About** — Short biography and portfolio overview
- **Skills** — HTML, CSS, JavaScript, and Accessibility, with descriptions
- **Projects** — Selected work from the Web Programming course

## Profile and projects

The hero photograph is an optimized JPEG made from Vision's original sunset photo and is stored at `assets/sunset.jpg`. The browser tab uses a matching SVG monogram icon from `assets/favicon.svg`. Mochi is a decorative SVG in `index.html`; the cat design is based on the existing `cat-buddy.html` artwork. The project cards link to the original course work:

1. **API Applications (Week 6)** — A collection of six browser applications that explore public data with JavaScript Fetch API.  
   [View the project](https://vision123-hub.github.io/WebProgramming_Assignment1/week%206/api-tasks.html)
2. **Book Finder (Week 7)** — Search for books using Open Library, browse results, and save favorites in the browser.  
   [View the project](https://vision123-hub.github.io/WebProgramming_Assignment1/week%207/book-complete.html)
3. **Accessibility Audit (Week 9)** — A Lighthouse report documenting course-site accessibility improvements.  
   [View the project](https://vision123-hub.github.io/WebProgramming_Assignment1/week%209/accessibility-report.html)
